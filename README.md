# 🖐 Gesture Control PRO

Управление компьютером жестами в двух режимах — без лишней нагрузки.

## Установка (один раз, в терминале VS Code)

```
pip install opencv-python mediapipe pyautogui numpy
```

## Запуск

```
python gesture_control.py
```

---

## Режимы

### 🚀 LAUNCHER (по умолчанию)
Удержи жест 2 секунды → запустится приложение.

| Жест | Действие |
|------|----------|
| ✊ Кулак | Play / Pause |
| 👍 Большой палец | Громкость + |
| ☝ Указательный | Google Chrome |
| ✌ Два пальца (V) | Калькулятор |
| 🤙 Шака | Блокнот |
| 🤟 Rock | Firefox |
| 4️ Четыре пальца | Проводник |
| 🔫 Пистолет | VS Code |
| 3️ Три пальца | Word |
| ✋ Открытая ладонь 2с | → РЕЖИМ УПРАВЛЕНИЯ |

### 🖱 CONTROL (управление курсором)
Двигай руку — курсор следует за указательным пальцем.

| Жест | Действие |
|------|----------|
| Указательный + большой (щипок) | Левый клик |
| Средний + большой (щипок) | Правый клик |
| Безымянный + большой (щипок + движение) | Скролл |
| ✋ Открытая ладонь 2с | → LAUNCHER |

---

## Выход
Нажми `Q` в окне камеры.

## Настройки (в начале gesture_control.py)

```python
HOLD_SECONDS   = 2.0   # время удержания жеста
COOLDOWN_SECONDS = 2.5 # пауза между действиями
SMOOTH_FACTOR  = 0.18  # плавность курсора (меньше = плавнее)
CAMERA_INDEX   = 0     # индекс камеры (0 = встроенная)
```

Приложения настраиваются в словаре `APPS` в начале файла.
