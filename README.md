## 📖 О проекте

**Hand Gesture Computer Control** — это приложение на Python, которое позволяет управлять компьютером с помощью жестов рук, распознаваемых через обычную веб-камеру. Используя мощь **MediaPipe** и **OpenCV**, система в реальном времени отслеживает положение пальцев и выполняет команды: открывает приложения, управляет музыкой и громкостью.

### ✨ Ключевые особенности

- 🎯 **13 уникальных жестов** — каждый жест выполняет конкретное действие
- ⏱️ **Удержание 2.5 секунды** — защита от случайных срабатываний
- 🔒 **Кулдаун 3 секунды** — предотвращение повторных срабатываний
- 📊 **Прогресс-бар на экране** — визуальная обратная связь
- 📋 **Cheat-sheet с жестами** — шпаргалка прямо в интерфейсе
- 💡 **Автокоррекция яркости** — работает даже при плохом освещении
- 🖥️ **Поддержка Windows 10/11**

## 🚀 Установка и запуск

### Предварительные требования

- Python **3.8** или выше
- Работающая **веб-камера**
- **Windows 10** или **Windows 11**

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/hand-gesture-control.git
cd hand-gesture-control
```

### 2. Создание виртуального окружения

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать (Windows)
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или вручную:

```bash
pip install opencv-python mediapipe pyautogui numpy
```

### 4. Запуск

```bash
python main.py
```

## 🎮 Как пользоваться

1. **Запустите** программу — откроется окно с изображением с камеры
2. **Поднесите руку** к камере на комфортное расстояние
3. **Покажите жест** и **удерживайте** его 2.5 секунды
4. Следите за **прогресс-баром** внизу экрана
5. После срабатывания появится кулдаун **3 секунды** перед следующим действием
6. Используйте **cheat-sheet** справа на экране, если забыли жест
7. Нажмите **`Q`** для выхода из программы

### 💡 Советы для лучшего распознавания

- 🌟 Убедитесь, что рука хорошо освещена (система автокорректирует яркость, но хорошее освещение всегда лучше)
- 📏 Держите руку на расстоянии **30–60 см** от камеры
- 🤚 Показывайте жесты **чёткими и статичными** — избегайте лишних движений во время удержания
- 🎯 Держите руку **в центре кадра** для наилучшего распознавания

## 🛠️ Технологии

```
Веб-камера → OpenCV (захват кадров) → MediaPipe (21 точка руки)
    → Классификатор жестов → Таймер удержания (2.5с)
        → Кулдаун (3с) → Выполнение действия (pyautogui)
```

**MediaPipe Hand Landmarks** отслеживает **21 ключевую точку** руки, что позволяет точно определять положение каждого пальца и классифицировать жест.

## ⚙️ Настройка

В файле `main.py` можно изменить параметры:

```python
HOLD_TIME = 2.5        # Время удержания жеста (секунды)
COOLDOWN_TIME = 3.0    # Кулдаун между действиями (секунды)
CAMERA_INDEX = 0       # Индекс камеры (0 - основная)
```
